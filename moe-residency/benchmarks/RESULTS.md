## 1. 端到端演示 `examples/demo_engine.py`

```
专家池 64 | 快层 16 | 内存 20 | token 540 | 6 域 × 3 轮（每域 30 token）
负载：全局共享热点 6 + 每域专属 8

======================================================================================
策略                   停顿miss    停顿miss率    总I/O    预取I/O     预取用到      逐位一致
--------------------------------------------------------------------------------------
lru                     123       5.7%      84        0        0         ✅
slru                    140       6.5%     100        0        0         ✅
prefetch                 93       4.3%      91       26       36         ✅
pinned                  135       6.2%      93        0        0         ✅
pinned_prefetch          99       4.6%      96       27       37         ✅
--------------------------------------------------------------------------------------
相对 LRU 的「停顿 miss」变化：  slru +13.8%  prefetch -24.4%  pinned +9.8%  pinned_prefetch -19.5%

五种策略 logits 全部与「全驻留」逐位相同 —— 换策略只改 I/O，不改语义。
预取把「当场等盘」变成「提前读、与计算重叠」：停顿降、总 I/O 略升，这是设计意图。
纯频率 pin / SLRU 在本负载无收益（共享热点一直在 LRU 里）——它们只在「工作集>>缓存」时才有用。
收益最大的是「纯域画像预取」：把切域后的一批冷 miss 提前搬走，与上一段计算重叠。
```
