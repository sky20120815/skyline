# 行为准则

## 我们的承诺

我们承诺让参与变得**无骚扰**，不论年龄、体型、身体状况、族裔、性别认同与表达、
经验水平、教育背景、社会经济地位、国籍、外貌、种族、宗教或性取向。

## 我们的标准

有助于本项目的：

- 聚焦技术、给出证据（实测数字 / 可复现代码）优先于观点
- 承认不知道、承认自己的测量有偏差（这比"看起来很确定"更有价值）
- 尊重他人的工作并署名（尤其是借鉴的部分）

不可接受的：

- 人身攻击、骚扰、贬低
- 无证据的夸大（例如把"理论估算"说成"实测"）
- 明知不成立却坚持的结论

## 执行

违规可通过 GitHub 私下联系维护者举报。所有举报都会被审阅与保密处理。

本准则改编自 [Contributor Covenant](https://www.contributor-covenant.org/) 2.1。
